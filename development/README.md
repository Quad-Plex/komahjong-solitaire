# Development Documentation

This directory contains the project's engineering documentation and implementation history. It
is not needed to install or use the plugin.

- [`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md) contains the locked design, architecture
  notes, and user-story index.
- [`implementation-plan/`](implementation-plan/) contains the detailed user-story documents and
  implementation history.
- [`../AGENTS.md`](../AGENTS.md) remains at the repository root because it is consumed as the
  repository's agent and contributor guidance.

For installation and gameplay instructions, see the [main README](../README.md).
